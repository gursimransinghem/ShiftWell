- `lumi-04-today-good-night-kray.png` (light-mode Today screen)
- `lumi-05-journal-free.png` ("The ink is listening…")

## Why this folder is gitignored

PNGs are large and shouldn't live in the repo's git history. The written distillation in `../LUMI-REFERENCE-2026-04-20.md` is what survives.

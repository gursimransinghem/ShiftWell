## 8. Security Audit

### npm vulnerabilities (ShiftWell app)
6 vulnerabilities found:
- **1 critical:** `node-forge` — basicConstraints bypass, signature forgery, DoS
- **3 high:** `picomatch` — method injection, ReDoS
- **2 moderate:** `yaml` — stack overflow via deep nesting

All fixable via `npm audit fix`. These are in transitive dependencies (dev tooling), not in production app code.

### Supabase security
- RLS enabled on all 6 tables
- All policies scoped to `auth.uid() = id` / `auth.uid() = user_id`
- Subscriptions table is read-only for users (Edge Functions handle writes)
- No service-role key exposed in client code

### Secrets handling
- `.env` properly gitignored
- `.env.example` contains only placeholder values
- No hardcoded API keys found in source code
- `EXPO_PUBLIC_*` prefix correctly used for client-side env vars

## 10. Recommended CI/CD Pipeline

```yaml
# .github/workflows/ci.yml
name: ShiftWell CI
on: [push, pull_request]

jobs:
  typecheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }
      - run: npm ci
      - run: npx tsc --noEmit

  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }
      - run: npm ci
      - run: npx jest --maxWorkers=50% --forceExit --passWithNoTests

  api-test:
    runs-on: ubuntu-latest
    defaults:
      run: { working-directory: api }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }
      - run: npm ci
      - run: npx tsc --noEmit
      - run: npx jest --passWithNoTests

  expo-doctor:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 22 }
      - run: npm ci
      - run: npx expo-doctor
```

# ShiftWell — Screenshot Specifications

> Device sizes, compositions, overlay text, and keyword strategy for App Store screenshots.
> CRITICAL: Apple now indexes screenshot caption text for search ranking (June 2025 algorithm update). Every caption must contain target keywords.

---

## Required Device Sizes

| Device | Resolution | Display Size |
|--------|-----------|-------------|
| iPhone 16 Pro Max | 1320 × 2868 px | 6.7" |
| iPhone 16 Pro | 1206 × 2622 px | 6.1" |
| iPhone 8 Plus | 1242 × 2208 px | 5.5" |

**Production note:** Design at 6.7" (1320 × 2868) as the master. Scale down for other sizes. All screenshots portrait orientation.

---

## Design System

| Element | Specification |
|---------|--------------|
| Background | Night Sky gradient: #0A0E1A → #1A1040 (matches app splash) |
| Caption font | SF Pro Display Bold, 56pt minimum (6.7"), white #FFFFFF |
| Caption position | Top 20% of frame, left-aligned with 48px padding |
| Sub-caption | SF Pro Display Regular, 32pt, #8B8FA3 (muted gray) |
| Device frame | iPhone 15 Pro Max, Space Black titanium |
| App UI | Actual screenshots from app in dark mode, populated with realistic data |
| Accent color | Warm gold #C8A84B for badges/callouts |
| Max words per caption | 6 words (exception: Screenshot 1 hero can be 8) |
